# Planning

Fight AccessControl owns its implementation planning locally.

- `specs/` contains product requirements and behavioral authority.
- `epics/` groups product requirements under durable delivery outcomes.
- `adr/` records accepted architecture and quality decisions.
- `tickets/` contains executable work and its board projection.
- `agents/` contains readiness, triage, architecture, and completion rules.
- `provenance/` records immutable sources adopted during repository bootstrap.

Run `./bin/planning-check` after changing any planning artifact.

The current delivery sequence is indexed in [ROADMAP.md](ROADMAP.md).
