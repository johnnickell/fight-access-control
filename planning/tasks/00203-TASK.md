# Adopt equivalent Fight Common Domain helpers

## What to Build

Start with the 12 production `email()` candidates in [WF-040](../wayfinder/research/WF-040-common-domain-helpers.md). Assess production callers for `string()`, `mb_string()`, `array_list()` and `hash_set()` against the minimum supported Fight Common v1.5.1. Use explicit function imports only for equivalent substitutions; retain class imports still needed for declarations. Document the preference and exceptions in the [local PHP standard](../../docs/engineering/standards/PHP.md).

## Acceptance Criteria

- [ ] Record candidates and justified exceptions for all five helpers. Do not manufacture uses where no equivalent caller exists. Preserve result types, normalization, exceptions and evaluation order, including hydration and authentication failure behavior at changed sites.
- [ ] For each typed collection replacement, pass the element class as the second argument. Verify both runtime element enforcement and the inferred PHPStan element type at each changed site. Retain the factory if inference widens to `mixed` or construction behavior changes; do not use casts or annotations to force a substitution.
- [ ] No dependency bump, blanket lint rule, test-only rewrite or changes to non-equivalent UUID or serialization behavior. No new package Commands, Queries, Events, permissions or persistence changes.

## Verification

Select the worktree before implementation. Verify equivalence against Common v1.5.1, run focused existing behavior checks for changed callers, ordinary PHPStan analysis and the affected type-contract probes. Save the canonical `./bin/build` receipt and run `./bin/planning-check`, `./bin/documentation-check` and `git diff --check`.

## Implementation

- Replaced 11 command/event hydration calls and one login parsing call with Common v1.5.1's `email()`. The helper invokes the same factory; argument order, validation and authentication failure handling are unchanged.
- Left the six typed list query handlers and four `User`/`Role` set initializations on `::of()`: the collection helpers do not preserve the inferred element type. No production string-object factory matched either string helper.
- Documented the [helper preference and exceptions](../../docs/engineering/standards/PHP.md#fight-common-domain-helpers). The ignored Work handoff records verification; acceptance remains independent.
