## Implementation

Both `bin/release` call sites use the same PHP checker in a locally prepared PHP CLI image. The standalone
command mounts the checkout read-only and disables networking; it does not need Git, Composer or `vendor/`.
The separate PHP qualifier checks valid and invalid fixture metadata without invoking Docker or certification.
The shared wrapper quotes Docker's mount fields so checkout paths containing commas remain exact.
Certification wiring was inspected without running it. Independent acceptance remains pending.
