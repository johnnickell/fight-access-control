  disables durable audit; configured failure never silently disables/discards it. Reuse existing required typed
  UserId actors and canonical Command/Event round trips, not nullable actor replacements, ambient/transport lookups,
  parsed labels or System/Anonymous fallback. Enabled attribution precedes the first audited mutation; existing
  required actors remain required even when disabled and no-change gains no new audit-only actor obligation.
- Establish one handler-owned transaction containing authoritative mutation and explicit evidence insertion before
  commit. Reuse cohesive assignment behavior while reconciling coordinator-owned commitTransactional calls so no
  inner/independent transaction commits early. Expose necessary authoritative outcome facts explicitly at their owner;
  do not infer business evidence by inspecting a returned Event or add a generic callback/lifecycle/audit framework,
  forwarding handler, UoW decorator or repository interceptor. Lower helper execution produces no duplicate record.
- Record direct typed actor, Agent/Permission relationships, unique evidence identity, trusted outcome time, actual
  message correlation and authoritative before/after assignment revisions. Complete replacement retains complete-set
  semantics, meaningful changed relationships and a single real assignment-revision advance, not a full Agent dump
  or per-incidental-write evidence. Unchanged relationships are not claimed to have changed.
- Preserve exact Agent/Permission identity, normalized set/deduplication/order, expected assignment revision,
  ADMIN_SAFE complete-set/grant eligibility, current definition/reference fences and complete-state CAS. Preserve
  existing allowed revocations of protected assignments; supplied actors/IDs/evidence grant no administrative entry,
  target/scope authority. Current cohort/lifecycle/credential/operation fences and unrelated state remain intact.
- Already-held grant, absent-membership revoke and valid identical-set replacement retain applicable validation,
  revision/definition/reference fences but produce no write/revision advance/success fact/mutation evidence. Empty
  replacement is a change when it removes real assignments. Never turn stale or ineligible intent into no-op success.
- Audit failure, concurrent tier/reference loss or CAS loss rolls back staged assignment/evidence together. Preserve
  primary throwable, uncertain commit and ordinary post-commit publisher/subscriber failure; committed evidence
  survives publication failure. No rejected-attempt durability, replay/outbox or Agent issuance warning exception.
- Evidence uses bounded action-specific typed/admitted facts, not entities/credential envelopes/issuance, raw messages,
  hashes/ciphertext, diagnostics or unnecessary personal data. Free text needs explicit admission; records are not
  automatically safe/public log or response payloads. Keep existing success facts after confirmed commit only.
