### Actors, Contracts and Effects

collaborator. No business Command, Query, Event, authentication, grant, persistence or external effect is added.
The outcome is one discoverable, internally consistent rule surface, not a source-conformance certification.

### Scope

- Update the applicable local Architecture, Naming and PHP guidance, project profile, CONTEXT/current architecture
  descriptions and standards-adoption amendment/digests as needed; link from AGENTS rather than duplicating rules.
- Specify Domain/{BoundedContext}/{Aggregate} roots/IDs/repositories, owned entities/values, verb-first messages and
  past-tense facts. Explain justified Domain services/DTOs and existing Common low-level primitives, not a rigid
  Entity-only test or a new generic contracts directory.
- Specify mirrored Application handlers/policy subscribers and semantic capabilities; Service is a fallback.
  Specify capability/aggregate Adapter presentation, with neutral Adapter/Mcp/{Tool,Resource,Skill}/Agent and
  aggregate-oriented persistence as a pattern, not authorization to add production persistence here.
- Keep dependency direction: Adapter owns third-party mechanisms/frameworks; Application may use PSR and upstream
  Application/Domain contracts; Domain may use pure PHP and upstream Domain contracts. Preserve explicit exceptions,
  optional framework isolation and Common ownership of protocol engines, neutral ports and existing use cases.
- Require descriptive properties, parameters and locals, including repository/query/command/event collaborators.
  Keep plural collection names where they really contain collections; avoid invented boilerplate or folder quotas.
- Reconcile WF-035/profile/ADR 0001's earlier layout restrictions visibly against the approved target, preserving
  history. Reconcile the single AuthenticationService placement requirement in ADR 0003/profile with TASK-00112's
  cohesive synchronous replacement while preserving sensitive non-serializable inputs and all behavior guarantees.
- Preserve QueryHandlers through Domain repositories, actual atomic repository capabilities, UoW separation,
  current-contract safety and ADR 0011. Do not copy unrelated provider rules or describe future source as implemented.
- Add source-linked Common coordination notes for consumed contracts, not guessed canonical APIs or package versions.
  TASK-00110 owns actual adoption; the remaining Common plans stay external evidence, never local dependency IDs.
