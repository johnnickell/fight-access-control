# Port the Unit coverage checker to PHP

## What to Build

Replace `scripts/check_unit_coverage.py` with a PHP entry point using the dev-only tooling namespace. Keep its inputs, outputs and exit behavior. The shared gate calls it directly in the prepared runtime; do not duplicate preparation or rerun PHPUnit. Update callers, docs and the Python inventory.

## Acceptance Criteria

- [ ] Equivalent accepted and rejected reports yield equivalent verdicts, Unit-only executable line attribution, suite counts and failure exits. Missing or malformed inputs fail rather than granting coverage credit.
- [ ] The single gate still enforces exact statement coverage, Unit-only line coverage and shipped OpenAPI checks. No change to coverage denominators or application contracts. Coordinate the benchmark with [TASK-00193](00193-TASK.md).

## Verification

Select the worktree before implementation. Compare old/new reports and exits; directly qualify the checker outside the product suite. Save the canonical `./bin/build` receipt and run planning, documentation-link and diff checks.

## Work evidence

The shared gate now invokes the PHP checker directly in its prepared runtime. The dev-only implementation reads
PHPUnit's native coverage once and retains the category manifest, report and inspection mode. No product,
test-suite, dependency, statement gate or OpenAPI inputs changed.

The checker comparison uses the same saved native artifacts for both implementations, separately from the
[TASK-00193 PHPUnit benchmark](00193-TASK.md). It does not retime PHPUnit or change that benchmark's baseline.
The timing reader validates the full log as UTF-8 before filtering events and accepts the same line endings as
the Python checker. Direct comparisons reuse saved PHPUnit artifacts, including the malformed and CR-only logs
from independent review. Duration parsing preserves the Python checker's decimal syntax and exact totals,
including values wider than a PHP integer, and rejects NUL bytes. The XML reader rejects NUL characters rather
than accepting a truncated document. The ignored Work handoff records exact subjects, paired reports and exits,
and the local gate receipt.
