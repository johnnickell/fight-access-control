# Port the Unit coverage checker to PHP

## What to Build

Replace the Python checker with a dev-only PHP entry point that reads the current PHPUnit artifacts produced
by the shared gate. Call it directly in the prepared runtime without duplicate preparation or another PHPUnit
run. Update callers, docs and the Python inventory.

The maintainer amended this task: the old coverage number, suite counts, report format and edge-case behavior
are not requirements. Neither comparison with the old checker nor a comparison-specific benchmark is required.
Prior reports remain historical evidence, not acceptance of the amended task.

## Acceptance Criteria

- [x] Unit tests hit 100% of executable source lines, including lines in unexecuted source. Integration and
  Functional hits cannot fill a Unit gap.
- [x] Missing required artifacts or errors in the supported native format fail cleanly. Obsolete artifact formats
  and Python compatibility are out of scope.
- [x] The single prepared gate still enforces exact all-suite statement coverage and the shipped OpenAPI checks.
  Do not change application contracts or the source scope of either coverage check.

## Verification

Use the selected checkout's native PHPUnit output. Run one normal `./bin/build` and save its receipt. Outside
of the product suite, use the same artifacts to show that the checker fails when only a non-Unit test hits a
source line and when required input is unavailable. Run planning, documentation-link and diff checks.
