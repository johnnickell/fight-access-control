# Port the Unit coverage checker to PHP

## What to Build

Replace `scripts/check_unit_coverage.py` with a PHP entry point using the dev-only tooling namespace. Keep its inputs, outputs and exit behavior. The shared gate calls it directly in the prepared runtime; do not duplicate preparation or rerun PHPUnit. Update callers, docs and the Python inventory.

## Acceptance Criteria

- [ ] Equivalent accepted and rejected reports yield equivalent verdicts, Unit-only executable line attribution, suite counts and failure exits. Missing or malformed inputs fail rather than granting coverage credit.
- [ ] The single gate still enforces exact statement coverage, Unit-only line coverage and shipped OpenAPI checks. No change to coverage denominators or application contracts. Coordinate the benchmark with [TASK-00193](00193-TASK.md).

## Verification
