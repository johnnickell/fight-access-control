## PHP port

The host planning and archive commands use one container per invocation on the prepared package image with
networking disabled. That container checks the stable PHP 8.5.12 floor on the 8.5 line before loading tooling.
The shared quality gate and archive apply call the same PHP validator directly. Board qualification exercises the production
renderer; archive qualification uses a disposable checkout. Archive apply rejects identifiers after an option
interrupts the identifier list, and planning views sort integer orders exactly. The planner rejects invalid
arguments before validation or regeneration. Archive retains the Python CLI's apply and help abbreviations.
The host wrappers mount the checkout writable only for valid write requests. Git subprocesses inherit standard
error so a combined file capture preserves both archive move lines and both planning summaries. The Work handoff
records the regression and verification evidence.
