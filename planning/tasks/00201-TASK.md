## Implementation handoff

`bin/build` keeps planning, dependency preparation and the single gate on the host side of the tooling boundary.
The PHP evidence processor runs without Composer in the selected tooling image. Native checkout selection,
Compose lifecycle, ownership checks and guarded Worktrunk removal stay behind `bin/runtime`. See the
[local tooling guide](../../docs/engineering/LOCAL_TOOLING.md) and
[migration inventory](../../docs/engineering/python-tooling-inventory.md). Before reusing a receipt, `bin/build`
resamples Git membership for fingerprinting. An unavailable snapshot cannot qualify reuse or replace a known gate
exit. Planning and preparation have host deadlines and stop before the gate on timeout. The wrapper reports the
timeout before a bounded wait for the local evidence transport. It identifies the host group, the container
when known, and the checkout lock to reobserve before retrying. The outer runtime watchdog covers nested
`bin/down` commands, including the admitted Worktrunk hook. Exact qualification results and any remaining
holds belong in the Work handoff.
