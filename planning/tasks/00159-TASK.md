## Contracts and Boundaries

- Add an optional last nullable AuditEvidenceRepository to both handlers: omitted/null intentionally disables durable
  audit, while configured writer failure never silently disables/discards it. Add optional direct typed actorId where
  absent; trusted callers establish actual provenance without transport/ambient lookup, guessed target actors, label
  parsing or fallback identities. Disabled/validated no-change needs no new audit-only actor input. When enabled,
  admit attribution before the first mutation needing evidence; existing required inputs/authorization remain intact.
- Explicitly insert typed Feature/action/relationship evidence within the actual mutation transaction/connection,
  after authoritative persistence and before commit. Capture unique evidence identity, real message correlation,
  trusted outcome time via the existing Application Clock contract and exact before/after Feature revisions. Include
  meaningful status or old/new Permission relationships without claiming referenced Permissions themselves changed.
  Do not invent persisted Feature timestamps, new revisions/preconditions or synthetic unrelated outcomes.
- Preserve immutable identity/name, positive expected revision and the single shared revision for status and binding.
  A real change advances once. Final replace compares complete expected state and holds the shared Permission-reference
  fence through commit. Validate selected/bound Permission even on no-op; stale same-value requests still reject.
  Broken binding cannot be laundered by status change and may be repaired only by an actual existing selected identity.
- A validated same-value selection writes/advances/publishes no mutation success and creates no evidence. Preserve
  missing target, stale state, malformed input and reference rejection versus unknown provider/native faults; audit
  is not permission to fabricate no-change or conceal operational failures. Any existing Permission tier is eligible:
  a Feature binding is not a Role/Agent grant, promotion restriction, availability decision or administrative authority.
- Audit failure or final-state/reference loss rolls back staged state/evidence together. Preserve primary throwable,
  uncertain commit and ordinary post-commit publication failure; committed evidence survives publisher/subscriber
  failure. No Agent issuance warning exception, independent audit commit, duplicate helper record or retry backfill.
- Bound action-specific safe facts explicitly. Exclude raw messages/entities/plan snapshots, secrets/hashes/ciphertext,
  diagnostics and unnecessary personal data; free text needs field-specific admission. Evidence is not automatically
  authorized public/log output. No returned-Event inference, UoW/repository interception or rejected-attempt store.
