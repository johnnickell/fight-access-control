# Keep Board next-action guidance truthful for blocked planning work

## Outcome

The generated Task Board names the first non-executable planning task that needs attention when no human-action,
in-progress, or executable ready task exists, instead of falsely reporting that no non-terminal task exists.

## Scope

- In scope: the Task Board generator's next-action fallback, a tooling-only regression qualification, regenerated
  planning views, and the current EPIC-00005 planning handoff.
- Out of scope: changing task readiness semantics or ordering, implementing EPIC-00005 product behavior, formal
  review, merge, release, deployment, cleanup, and hosted-CI inspection.

## Acceptance Criteria

- [x] A Board whose only non-terminal task is `needs-info` surfaces that task under **What's Next?** and does not
      claim that no non-terminal task exists.
- [x] A Board whose only non-terminal task is `needs-triage` likewise surfaces that task without treating it as
      executable.
- [x] Existing precedence remains `ready-for-human`, `in-progress`, executable `ready-for-agent`, `needs-info`,
      then `needs-triage`.
- [x] The focused tooling qualification, generated-view check, documentation check, and complete project gate pass.
