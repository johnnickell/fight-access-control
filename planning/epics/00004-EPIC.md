# Composable OpenAPI Schema Components

## Destination

Publish reusable PHP OpenAPI schema components that a Fight AccessControl consumer scans alongside its own models and
assembles into its own OpenAPI document. The release documents every public Command, Query, authentication payload,
safe result, collection, creation result, and optional JSend success envelope without creating a package-owned
transport adapter, endpoint, root document, or documentation UI.

## Decisions so far

- `openapi/` is a non-autoloaded metadata distribution with a consumer generator bootstrap; Domain and Application
  retain their current dependency boundary.
- `swagger-php ^6.5` is a development dependency and Composer suggestion, supplied by each consuming project.
- Schema keys use the stable `Fight.AccessControl.*` dot namespace and are public `0.x` contracts.
- Browser and portable authentication token responses are distinct so a refresh credential can remain `HttpOnly`.
- Typed JSend success envelopes are optional; failure and error mapping remain consumer-owned.
