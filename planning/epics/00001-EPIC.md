# Identity, Credential, Session, and Account Lifecycle

## Destination

Deliver PRD-00017 as coherent framework-neutral Domain and Application slices, then prove the same observable
outcomes through consumer-owned adapters in each starter repository before authorizing a public release.

## Decisions

- Fight AccessControl owns shared identity, credential, session, authorization, and account-lifecycle behavior.
- Production dependency direction is `Domain <- Application`; there is no production Adapter layer.
- PRD-00017 is the repository-local behavioral and security authority.
- Detailed capability tickets are created locally after bootstrap authority is accepted.
- Release milestones remain gradual `0.x` decisions; no bootstrap work authorizes a tag or `1.0.0` stability.

## PRDs

- PRD-00017 — Fight AccessControl Identity and Authentication Lifecycle

## Out of Scope

Framework adapters, composition roots, infrastructure implementations, detailed capability tickets during the
bootstrap, public visibility, version tags, Packagist publication, and release publication.
