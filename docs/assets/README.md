# FIGHT Access Control identity

The README uses `fight-access-control-light.svg` on light surfaces and `fight-access-control-dark.svg` on dark
surfaces. Both are self-contained SVGs with accessible titles/descriptions and no scripts or external resources.

The Inward Port mark and outlined FIGHT wordmark retain the Fight family artwork used by
[Fight Agent OS](https://github.com/johnnickell/fight-agent-os/tree/develop/docs/assets) and
[Fight Common](https://github.com/johnnickell/fight-common/tree/main/docs/assets/identity).
Only the product descriptor and its letter spacing are adapted to ACCESS CONTROL; light/dark colors are retained.
The descriptor uses the same local Arial/Helvetica/sans-serif fallback stack as Agent OS. Assets are distributed
under this repository's [MIT License](../../LICENSE).
